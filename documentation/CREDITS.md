# EduSense AI 360 — Credits

## Built with
- **Gradio** — application UI
- **OpenCV** — image handling
- **MediaPipe** — face detection and FaceMesh (iris) landmarks
- **FER / DeepFace** — facial emotion recognition
- **NumPy, Pandas** — numerical processing
- **Plotly** — interactive dashboard charts
- **ReportLab** — PDF reports (with native charts)
- **OpenPyXL** — Excel reports
- **psutil** (optional) — CPU/memory monitoring

## Acknowledgements
EduSense AI 360 is an educational analytics project. It is designed for supportive,
constructive classroom insight and adheres to its ethical principles: privacy,
transparency, fairness, no diagnosis, no identity recognition, and educational use
only.
